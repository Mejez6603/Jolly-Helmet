Coin check: on the INSERT COIN screen the acceptor power should read ON. Insert a coin: "pulses B1 has counted" should rise by the coin's value within a second or two, and B1 beeps. If it stays the same, the coin signal is not reaching B1. The "coin wire" line counts every pulse edge B1 sees BEFORE its filter: if a 20-peso coin shows 20 edges but only 1 pulse counted, B1's filter is eating them; if it shows 1 edge, the acceptor itself only sent one pulse for that coin.

Rules (time, coins, free retry)

Box 3 starts with a copy of Box 1's prices - set Box 3's own here. Rating bands: each rating from 1 to 10 should fall in exactly one band. The free retry is offered once when EITHER rating after a cleaning (odor or dryness) is in the free range.

Cleaning phases (which relays run when)

The cleaning is cut into a START part, a MIDDLE part (whatever is left) and an END part, and each relay is ON or OFF in each. Defaults: UV the first and last minute, humidifiers in the middle, heater + UV the last minute. The heater is a hair dryer: keep it in the END part only, never together with the humidifiers. If phasing is switched off for a cleaning, the heater stays OFF. The parts count real cleaning time, so a pause does not use them up. If the two parts overlap, the start wins.

Drying

After every drying, and after an abort during a drying, nothing runs for this long before the door can be opened (Box 3 has no fan). Default 60. The drying length itself comes from the customer's rating and the Rules above.

Maintenance

Only works when the S3B is on the idle (TAPS) or OUT OF ORDER screen. While on, the relays below are switched by hand; the enclosure lock rests itself after 60 s. Careful with the heater: a hand-set heater switches itself off after 5 minutes, and leaving Maintenance switches everything off - keep the door shut and a helmet out of the way when testing it.
