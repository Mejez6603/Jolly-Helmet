Is a sensor still working?

The station checks every water-level sensor all the time. It cannot see inside the container, so it only catches the faults that show in the reading.

Check a sensor by hand:

  1. Open the Refilling Station page and watch the raw value of that box. Dry, it reads about 0 and stays steady. Put the probe in water: the number rises and the level changes. Take it out: it falls again.
  2. Wiggle the SIG wire. The reading must not jump about.
  3. On the serial console (115200) type sensors: it prints, for every sensor, the average, the smallest and biggest reading of the last second, the spread, and whether it looks fine. raw streams the readings.
  4. Use Test valve on a container that is not full: with the supply on, the raw value should climb after a few seconds.
When the hardware team has chosen the sensor, pull its SIG wire and type sensors. If a disconnected wire reads something different from a dry sensor, the limits can be tuned to catch that too.

A sensor that reads 0 by mistake (unplugged, wrong wire, probe out of the liquid) looks like an EMPTY container, so the station keeps trying (valve open up to 30 seconds, then a pause of 60 seconds). The sensor check (next part) catches a wire on the 3.3 V rail and a floating wire, but not a dead sensor that reads 0. If a container is really full, close the supply and fix the sensor wire first. A drip tray under the containers is a good idea.

Close the water supply. On the Refilling Station page read the raw value of that sensor (a dry one reads 0), or type sensors on the serial console. Fix the SIG wire and the probe, then set the edges again. The station tries again every 60 seconds by itself.
