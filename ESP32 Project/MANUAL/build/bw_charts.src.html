One chart per stage of a run, with the same screen names the customer sees. A black rounded box is where a chart starts or ends. White boxes are screens or steps. A box with a thick border is where the machine is running. A box with a double border is a fault. A diamond is a decision. A thin rounded box says where the chart goes on. A dashed box is a note.

Start at the black box at the top. Answer each question (the diamonds) with yes or no and follow the arrow. Boxes with a thick border tell you what to do. These trees cover the problems that happen most; the tables in the Admin and Technician guides have the rest.
