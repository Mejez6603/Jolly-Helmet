  • A sensor that is unplugged or reads 0 looks like an EMPTY container, so the station keeps trying (valve open up to 30 seconds, then a pause of 60 seconds). If a container is really full, close the supply and fix the sensor wire first. A drip tray under the containers is a good idea.
