Which machine is free?

Look for the QR sticker on the machines. Scan it with your phone camera. A page opens that shows Box 1, Box 2 and Box 3 as FREE, IN USE (with about how many minutes are left) or OUT OF ORDER. You do not need an app or a password. The button at the top changes the language between English and Filipino.

Tip / Paalala: I-scan ang QR sticker para makita kung aling makina ang libre. Pindutin ang "Filipino" sa itaas ng page.

Online page (Monitor, Alerts, Reports)

The online page shows your machines on a phone or a PC, wherever you are. It only watches: nothing on it can start, stop or change a machine. Open it with the address your technician gave you. The first time it asks for the Blynk token: paste it once, it stays in that browser.

Level dials

Every container has a dial. 0 is the refill line: a box stops cleaning there. The dial is green when the container is fine, amber from the early warning line (30 %) and red under 15 %. So you can refill before a box shows OUT OF ORDER. Under each dial the page says whether the level is falling and about how long it will last.

When something needs attention the page shows a banner, puts a number on the tab and the tab icon, and plays a sound. Every kind of alert has its own sound, so you can tell them apart without looking.

  • Revenue and customers per day for the last 14 days, with the 7-day average, and this week against the week before.
  • Busiest hours and busiest days: when the customers come.

Checklist and Fix it

The Checklist follows the maintenance schedule of the Technician guide. Tap a machine under a check when you have done it there. The page shows when each check was last done and what is due. It is saved in the browser you use: use Save a backup to move it to another phone.

Fix it asks one yes / no question at a time and ends with what to do. If an alert is on, the matching guide is suggested at the top.

Customer status page (a second Blynk device)

The customer page (status.html) shows Box 1, Box 2 and Box 3 as FREE, IN USE or OUT OF ORDER. It is public, so it must not use your private token (a Blynk token can also write). It reads a second Blynk device that holds nothing but those three boxes.

  1. In the Blynk Console open Devices, New Device, From template, and pick the same template as before. Name it Jolly Helmet Public status.
  2. Open it, tab Device info, and copy its Auth Token. This token may be public. Never use the private token here.
  3. Open the Online Server setup page (Wi-Fi JollyHelmet-Online). Paste the token into Public status device token and tap Save and connect. The row Public status device on top then says OK.
  4. In the folder ONLINE_WEB open js/config.js and write the token in publicToken. (If you leave it empty, the QR code carries the token in the address.) Edit the prices and the "Something wrong?" line in the same file.
  5. Put the folder on the web host. Open the online page and tap the QR button. Paste the public token if it asks. Tap Print the sign and stick it on every machine.
  6. Test it: scan the QR code with a phone. The boxes must show FREE or IN USE. status.html?demo shows made-up data.
The public device holdsMeaning
bFor Box 1, Box 2 and Box 3: the step number, the seconds left and whether the brain is heard. Nothing else.
seq, ts, ivA counter, the time and the upload interval. The page shows NO INFORMATION when the data is older than about 4 minutes.
If somebody misuses the public token, the worst they can do is write a wrong status into that one device (the next upload overwrites it within a minute) and use up some Blynk messages. They cannot reach the private device, the revenue or the machines. The page costs one more Blynk message per upload.

Online Server firmware of 2026-10-10

Flash ESP32_ONLINESRV again (same settings, see Firmware and flashing). The new version:

  • counts every finished session per box, per hour of the day and per weekday, from the brains' own counters, and keeps the counts inside the board (this feeds Busiest hours, Busiest days and What each box earns in the Reports tab);
  • writes the public status device when its token is set;
  • shows two new rows on its setup page: Public status device and Sessions counted, and has a button Reset the per-box and busiest-hours statistics under More settings.

Until it is flashed, the three charts above say "Needs the Online Server firmware of 2026-10-10". Everything else works with the old firmware.

Alerts when the page is closed (Blynk app)

A closed page cannot make a sound. The Blynk app can.

  1. On the Online Server setup page tick Send a Blynk event with code alert, then Save and connect.
  2. In the Blynk Console open the template, tab Events, and make sure the event with the code alert exists (see Step 1). Choose the type Warning or Critical and switch on its push notification. Click Save.
  3. Install the Blynk app on the phone, sign in with the same account and allow notifications. Every new alert (box out of order, tank empty, container low, board offline) now arrives as a notification, even with the page closed.

The Manual tab and the team password

The customer chapters of this manual are public. The rest (admin, technician, reference) prints the Wi-Fi passwords, so the web page keeps it encrypted: the file on the web host is unreadable without the team password, and the page decrypts it in the browser after the password is typed. The team password is not the Blynk token.

After you change this Word file: press Ctrl+A, then F9 in Word (updates the contents and the index) and save. Right-click MANUAL\build_web_manual.ps1 and choose Run with PowerShell. It asks for the team password (use the same one, or a new one and tell the team). It makes a fresh PDF next to the Word file and rewrites the folder ONLINE_WEB\manual. Upload that folder again. Word must be installed on that PC.
