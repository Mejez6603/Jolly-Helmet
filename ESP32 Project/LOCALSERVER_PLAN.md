# LocalServer = the technician's Control Center (2026-10-03)

The LocalServer was rewritten so that EVERYTHING that needs changing or calibrating on the deployed unit can be done from a phone.
It replaces the old dashboard (A2-relay tabs, Box 1 tab, 4-tank ACS tab, and a Settings tab that pushed the OLD settings list into the new
nodes). The old files are archived in `ESP32_LOCALSRV/legacy_dashboard/` (`ESP32_LOCALSRV_LEGACY_pre_hub.ino.txt`, `index_html_LEGACY.h.txt`,
`script_js_LEGACY.h.txt`).

## Use
1. Power the unit (all nodes), flash `ESP32_LOCALSRV`, join Wi-Fi **`JollyHelmet-Local`** / **`12345678`**, open **http://192.168.4.1**.
2. Home: who is online (13 nodes), what each box and each ACS is doing, alerts (EMPTY supplies, low mixers, OUT OF ORDER, CLEANING greyed out), revenue.
3. **Box 1 / Box 2 / Box 3 / ACS 1-2 pages** (`/box1` `/box2` `/box3` `/acs`, also the big buttons on Home):

| Page | Settings it edits | Calibration helpers | Maintenance |
|---|---|---|---|
| Box 1 (S3A) | LEVELS (container lines, helmet distance, water sensors, refill tries, ACS requests), RULES (bands, price, max, free retry), PHASES (cleaning relays by part) | "use live" for every distance, dry/wet capture for the two water sensors | hand-set 12 relays |
| Box 2 (S3C) | HEAT (helmet distance, cool-down seconds), RULES | "use live" for the helmet distance | hand-set 6 relays (heater auto-off 5 min) |
| Box 3 (S3B) | LEVELS, RULES, PHASES (paid AND free, 6 relays incl. the heater, warning if heater + humidifier share a part), DRYING (cool-down) | same as Box 1 | hand-set 13 relays |
| ACS 1 / ACS 2 | LEVELS (empty / top-up / low / full per mixer), MIX (water share), TIMING (no-rise, shot, retry...) | "use live" lines, WL dry/wet capture, "pretend to be the box", retry now, accept mixers | hand-set 6 pumps |

Every page shows the node's own saved values (the nodes re-broadcast them every few seconds), fills the form from them, and tells you "S3x has these values ✓" once a Send was accepted.

## How it works
- The LocalServer only LISTENS and SENDS: each node keeps its settings in its own flash and runs its own state machine, so this board can be switched off, swapped or reflashed at any time without stopping a machine or losing a setting. It stores only the revenue statistics (and the pulse baselines).
- It sends the same messages the old benches sent (`CMD_SET_CONFIG`, `CMD_SET_MAINTENANCE`, `CMD_SET_RELAY_MASK`, ACS pump / request messages). To S3A / S3C it goes by unicast once their MAC is learned; to S3B / ACS 1 / ACS 2 by broadcast.
- Code: `ESP32_LOCALSRV.ino` (AP, stats, ESP-NOW), `settings_hub.h` (what each page shows + its API under `/api/b1|b2|b3|acs/...`), `settings_pages.h` (the four pages, GENERATED by `tools/build_hub_pages.ps1` from the bench pages + `tools/box3_page.html`), `index_html.h` / `script_js.h` / `style_css.h` (Home).
- Revenue now also counts Box 3 (B1's coin counter, S3B's sessions).

## Still open
- Never run on the real LocalServer board: compiled (87 % of flash) and each page tested in a browser against mock node data (state, forms, every send address, phone width).
- The benches (`ESP32_S3A/S3C/ACS_CONFIG_BENCH`) are no longer needed for deployment; keep them as spares (never run both at once - the same Wi-Fi channel, the same commands).
- Box 3 prices are a copy of Box 1's until set on `/box3`; "one minute of heat" is a setting there (PHASES).

## Screen refresh (added the same day)
Each box page has a **Screen (touch display)** section: a *Force refresh the screen* button, and a table with two ticks per relay (*when it turns ON* / *when it turns OFF*) saying which relay changes make the box restart its touch screen by itself (the white-screen cure). Stored in the S3 node's flash. Defaults: Box 1 and Box 2 = the enclosure lock engaging (the lock's OFF tick, since ON = unlocked); Box 3 = lock engaging plus the heater switching either way. The Home page has a *refresh screen* link per box. Needs S3A, S3B and S3C reflashed.

## Auto hard refresh (2026-10-05)
A field in each box page's Screen section: *Auto hard refresh every [2] seconds* (0 = never, 60 = max). The box's S3 re-sends its terminal's current page as a full controller re-init that often. Skipped on the rating and time-entry screens. Default 2 s - if the blinking bothers customers use 10-30 s or 0. Needs S3A, S3B, S3C and LocalServer reflashed; the terminals and the other boards are unchanged.
