Conceptual Framework of the JOLLY HELMET (Input-Process-Output with Feedback)

INPUT

Hardware and materials
  • ESP32 / ESP32-S3 microcontrollers
  • Touch screen and coin acceptor
  • Ultrasonic, door and water-level sensors
  • Relays, fogging nozzles, UV-C lamps (254 nm), heater and fan
  • Solenoid door locks and valves
  • Helmet disinfectant fogging solution
  • Power supply
Software and tools
  • Arduino IDE (C++ firmware), ESP-NOW radio
  • Blynk cloud
  • Web page (HTML, JavaScript) on GitHub and Vercel
User and administrator input
  • Helmet and coins
  • Mode choice: cleaning and drying, or drying only
  • Coin rate, refill and sensor settings
  • Records of the previous customers (ENTRY board)

PROCESS

A. System development (prototype model)

  1. Requirements and design of the three boxes
  2. Wiring, enclosure and sensor placement
  3. Firmware for each board (state machines)
  4. LocalServer Control Center, Online Server and website
  5. Bench testing, then implementation and testing with the users
  6. Evaluation and revision based on the users' feedback

B. Machine operation for each customer

Insert coins → choose the mode → sensors check the helmet, the door and the container → CLEANING: disinfectant fogging + UV-C (254 nm) → DRYING: heater + fan → the door opens, take the helmet

C. Data flow

Machine boards → (ESP-NOW) → Local Server → Online Server → (Blynk) → website
The Refilling Station keeps the main container filled
Sessions, statistics and alerts are kept on both servers

OUTPUT

For the customer
  • Cleaned, disinfected and dried helmet
  • Status page: FREE, IN USE, OUT OF ORDER
For the owner and administrator
  • Revenue and usage statistics (customers, coins, session time)
  • Real-time monitoring: Control Center and online page
  • Alerts: container low, out of order, door opened during a run
  • Reports (CSV, print or PDF)
For the team
  • User manual and technician guide
  • Tested prototype, revised after the users' feedback

FEEDBACK

The comments and observations of the users (odor that was not fully removed, ease of use, requests to clean other items), the sales statistics and the fault alerts guide the revisions to the cleaning solution, the UV-C lamp and the customer flow, the price and time settings, the refilling of the container, and the maintenance of the machine.
